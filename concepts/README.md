# Concepts

The shadow layer. Ideas enter here before they have an origin.

## Lifecycle

```
shadow → emerging → graduated
```

- **shadow** — present but unnamed. pressure only. no form yet.
- **emerging** — taking shape. being reviewed. developing structure.
- **graduated** — left the shadow. has an origin in another repo/system.

Graduation is correct. It is what is supposed to happen.
But it creates pressure. That pressure is documented here.
