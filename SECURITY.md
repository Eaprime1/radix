# Security Policy

## Supported Versions

Radix is currently in active development. Security updates are applied to the
latest revision on `main` only. No versioned releases have been cut yet.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

To report a vulnerability, open a [GitHub Security Advisory](https://github.com/Eaprime1/radix/security/advisories/new) in this repository.

Please include:
- A clear description of the vulnerability and the affected component
- Steps to reproduce or a proof-of-concept
- Potential impact assessment

**Response timeline (all calendar days from submission):**
- Acknowledgement within 3 calendar days
- Status update within 7 calendar days
- Fix or mitigation target within 30 calendar days for confirmed issues

If a report is accepted, you will be credited in the fix commit and release notes.
If a report is declined, a brief explanation will be provided.
